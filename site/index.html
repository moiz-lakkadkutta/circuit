ngspice said exit 0.
The answer was still wrong.

Modern ngspice recovers from many problems on its own — and when it can't, it often returns exit code 0 with a plausible but wrong answer: a relaxed fallback estimate, or arbitrary voltages on an ungrounded node. Nothing warns you. spiceguard answers one question: can I trust this result?
